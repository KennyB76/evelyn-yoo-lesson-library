### Block 2: Geometry Honors Prep — Coordinate Geometry (16:15~17:00 · 45분)

**Why this first:** HM Geometry Honors placement 출제율 높음 + Algebra 1 skill 직접 활용 → 약점 reinforcement 자연 통합

**Topics (순서대로):**

1. **Distance Formula** (10분)
   - $d = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}$
   - Pythagorean theorem 연결
   - 2 examples + 3 practice

2. **Midpoint Formula** (10분)
   - $M = \left(\frac{x_1+x_2}{2}, \frac{y_1+y_2}{2}\right)$
   - "average" 직관 설명
   - 2 examples + 3 practice

3. **Slope** (15분)
   - $m = \frac{y_2-y_1}{x_2-x_1}$
   - Parallel (same m) / Perpendicular (negative reciprocal)
   - Special cases (horizontal m=0, vertical undefined)
   - 3 practice

4. **연결 문제** (10분)
   - 점 3개 주어지면 → distance + midpoint + slope 모두 계산
   - 삼각형 종류 판별 (right/isoceles/scalene)
   - 1-2 문제
